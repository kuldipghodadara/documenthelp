## 🧑‍💻 How to Run Locally

You can run the project locally using your preferred IDE. Follow the steps below:

### Prerequisites

- Node.js & npm installed  
  Recommended installation method: [nvm (Node Version Manager)](https://github.com/nvm-sh/nvm#installing-and-updating)

### Steps

```sh
# Step 1: Clone the repository
git clone git@github.com:kuldipghodadara/documenthelp.git

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
